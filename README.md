# Mit AI Technology — الموقع الإلكتروني والباك إند (Django)

موقع وخادم شركة **Mit AI Technology** (شركة التحول الذكي للأنظمة):
- **الواجهة الأمامية (Frontend):** مبنية بـ React.js + Vite بهوية بصرية متكاملة وشخصية "Mit" الروبوتية المساعدة.
- **الخادم والباك إند (Backend):** مبني بـ Python و Django مع قاعدة معرفية ذكية (Knowledge Base)، نظام مرن للتبديل بين النماذج اللغوية (Qwen 2.5 / OpenAI / Groq / Gemini / Ollama)، وتخزين كامل للمحادثات وطلبات الاستشارة.

---

## 🚀 التشغيل السريع

### 1. تشغيل الباك إند (Django Backend)

تم تجهيز بيئة العمل الافتراضية داخل مجلد `backend/.venv`:

```bash
# تشغيل خادم Django على المنفذ 8000
cd backend
.\.venv\Scripts\python.exe manage.py runserver 8000
```

يفتح الخادم على: `http://127.0.0.1:8000`.

### 2. تشغيل الواجهة الأمامية (Frontend)

في نافذة موجه أوامر أخرى:

```bash
cd frontend
npm run dev
```

يفتح الموقع على: `http://localhost:5173`، ويقوم Vite تلقائيًا بتوجيه طلبات `/api` إلى خادم الباك إند.

## 🧠 ضبط نماذج الذكاء الاصطناعي (`backend/.env`)

الباك إند يحتوي على محرك ذكي مدمج وقاعدة معرفية تفصيلية عن الشركة وخدماتها وشخصية Mit، ويعمل افتراضياً ومحلياً 100% دون الحاجة لأي مفتاح مدفوع.

للتبديل لأي نموذج ذكاء اصطناعي، عدل ملف `backend/.env`:

### 1. الوضع الافتراضي (قاعدة المعرفة الذكية - مجاني ومحلي)
```env
AI_PROVIDER=knowledge_base
```

### 2. الربط مع OpenAI
```env
AI_PROVIDER=openai
AI_API_KEY=sk-...
AI_MODEL_NAME=gpt-4o-mini
```

### 3. الربط مع Groq (فائق السرعة - يدعم Qwen و Llama)
```env
AI_PROVIDER=groq
AI_API_KEY=gsk_...
AI_MODEL_NAME=llama-3.3-70b-versatile
```

### 4. الربط مع Google Gemini
```env
AI_PROVIDER=gemini
AI_API_KEY=AIzaSy...
AI_MODEL_NAME=gemini-1.5-flash
```

### 5. الربط مع نموذج محلي (Ollama أو سيرفر Qwen 2.5 محلي)
```env
AI_PROVIDER=ollama
AI_API_BASE=http://localhost:11434
AI_MODEL_NAME=qwen2.5:latest
```

> **ملاحظة أمان واستقرار:** إذا حدث انقطاع في الاتصال أو انتهى رصيد الـ API، يقوم الخادم تلقائياً بالتحويل السلس (Fallback) إلى قاعدة المعرفة الذكية لضمان استمرار خدمة زوار الموقع دون توقف.

## 📊 لوحة تحكم الإدارة (Django Admin)

يمكنك الدخول إلى لوحة التحكم عبر المتصفح:
- الرابط: `http://127.0.0.1:8000/admin/`
- اسم المستخدم: `admin`
- كلمة المرور: `admin123456`

من خلالها يمكنك:
1. الاطلاع على جميع طلبات الاستشارات والتواصل وتحديث حالتها (جديد، تم التواصل، تم تحديد موعد).
2. مراجعة جلسات وسجلات محادثات زوار الموقع مع المساعد Mit بالكامل.
