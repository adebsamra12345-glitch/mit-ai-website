# Mit AI Technology — الموقع الإلكتروني

موقع الشركة مبني بـ **React.js + Vite**، بالاعتماد على الهوية البصرية
والمحتوى المعتمد، وبشخصية "Mit" الروبوتية كمساعد رقمي (مدرّب على Qwen 2.5)
يظهر كزر محادثة عائم في كل صفحات الموقع.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح الموقع تلقائيًا على `http://localhost:5173`.

## البناء للإنتاج

```bash
npm run build
npm run preview   # لمعاينة نسخة الإنتاج محليًا
```

الناتج يكون في مجلد `dist/`، جاهز للرفع على أي استضافة استاتيكية (Netlify،
Vercel، أو أي خادم Nginx/Apache).

## هيكلية المشروع

```
src/
  assets/mascot.jpg        الشخصية الروبوتية (من الهوية البصرية)
  components/
    Header.jsx              شريط التنقل العلوي
    Hero.jsx                قسم الواجهة الرئيسية
    WhyUs.jsx                قسم "لماذا Mit"
    Services.jsx             الخدمات الثلاث
    Assistant.jsx            قسم المساعد الرقمي
    About.jsx                 "من نحن"
    CTA.jsx                    دعوة لاتخاذ إجراء
    Footer.jsx                  التذييل ومعلومات التواصل
    ChatWidget.jsx               ودجت المحادثة العائم (شخصية Mit)
  lib/
    assistantClient.js           طبقة الاتصال بخادم نموذج المساعد
```

## ربط المساعد الرقمي (Qwen 2.5) بخادم فعلي

الموقع يعمل حاليًا بوضع تجريبي (mock) لردود المساعد حتى تكون جاهزًا بخادم
النموذج. للربط الفعلي:

1. جهّز خدمة الـ backend التي تستضيف نموذج Qwen 2.5 المدرّب (Fine-tuned) —
   عبر RAG أو خط أنابيب مخصص — وتعرض endpoint بالشكل:

   ```
   POST /api/chat
   Body:     { "message": "نص المستخدم", "sessionId": "معرف اختياري" }
   Response: { "reply": "رد المساعد" }
   ```

2. أنشئ ملف `.env` في جذر المشروع:

   ```
   VITE_ASSISTANT_API_URL=https://your-api-domain.com/api/chat
   ```

3. في `src/lib/assistantClient.js`، غيّر `USE_MOCK` إلى `false`.

4. للمكالمات الصوتية: يمكن إضافة تكامل WebRTC / WebSocket بنفس الطبقة
   (`assistantClient.js`) لاحقًا دون تعديل واجهة المستخدم.

## ملاحظات

- الموقع بالكامل بلغة عربية واتجاه RTL.
- الخط المستخدم: Tajawal (عبر Google Fonts).
- الألوان والهوية مطابقة لملف الهوية البصرية المرفق (الأزرق الرمادي الداكن
  مع لمسة برتقالية للتباين والدعوات لاتخاذ إجراء).
- زر المحادثة العائم يظهر في كل الصفحة ويحمل صورة شخصية Mit.
